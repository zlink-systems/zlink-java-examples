# ZLink Java · Kotlin examples

[zlink-systems/zlink](https://github.com/zlink-systems/zlink)의
`framework/languages/java/`를 내보낸 읽기 전용 미러다. `main`은 최신 릴리스에 그 뒤의
수정을 더한 것이고, 릴리스는 태그 `vA.B.C`(framework 버전)다. 이슈와 PR은 원본 저장소로
보낸다 — 이 저장소는 PR을 받지 않는다.

| 디렉터리 | 목적 |
|---|---|
| [`quickstart/`](quickstart/) | 설치부터 첫 응답까지. 기능을 더하지 않는다 |
| [`tutorial/`](tutorial/) | 기능을 차례로 쌓는다. 기능별 가이드가 이 코드를 읽는다 |
| [`samples/`](samples/) | 완결된 업무 흐름을 보이는 application |

각 디렉터리의 README가 전제 조건·빌드·실행·검증 절차를 적는다. 문서는
[zlink.systems](https://zlink.systems)에 있다.

영어 대응 문서는 [README.md](README.md)다.
